À jour Aperçu du site
Comment ça marche : modifiez l'image, le nom, le prix ou la description directement ci-dessous. Tout est enregistré automatiquement sur cet appareil. Cliquez sur « Aperçu du site » pour voir le résultat, puis sur « Publier en ligne » pour que vos clients voient les changements.
Vitrine animée : les photos défilent et bougent sur la page d'accueil, juste sous les catégories. Pour chaque carte, changez la photo, le titre et le texte. Vous pouvez aussi ajouter une mini-vidéo (MP4, 25 Mo maximum) : elle se lance toute seule, sans son, quand le visiteur arrive sur la section. Pour envoyer une vidéo, il faut d'abord avoir collé votre clé dans l'onglet Publication.
Ajoutez autant de catégories que vous voulez et donnez-leur le nom de votre choix. Chaque produit est ensuite rangé dans une catégorie ; tous les produits apparaissent dans la boutique.

Publier en ligne

Le site est hébergé gratuitement sur GitHub Pages. Pour publier vos modifications depuis cette page, collez une fois votre clé d'accès GitHub (jeton personnel avec le droit « Contents : Read and write » sur le dépôt). Elle reste uniquement dans ce navigateur. La mise en ligne prend ensuite 1 à 2 minutes.

Sauvegarde

Téléchargez une copie de votre catalogue (fichier catalogue.js) pour la garder ou la remplacer manuellement dans le dossier data/ du site.
